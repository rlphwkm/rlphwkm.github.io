Wazuh SIEM Management & Deployment

Welcome to my write-up on deploying Wazuh in a homelab environment. In this post, I will walk you through the architecture, the installation process using VMware, and how to start collecting logs.

1. Why Wazuh?

Wazuh is a free, open-source security monitoring solution that collects, aggregates, indexes, and analyzes security data. It's incredibly powerful for both host-based intrusion detection (HIDS) and log analysis.

"Visibility is the foundation of security. You cannot protect what you cannot see."

2. Setting up the Environment

Before deploying the manager, you need to ensure your virtual environment is ready. Here are the specs I used for my VMware instance:

  • OS: Ubuntu 22.04 LTS
  • RAM: 8GB minimum (16GB recommended)
  • CPU: 4 vCPUs
  • Storage: 100GB SSD

3. Installation Commands

To install the Wazuh indexer, server, and dashboard, you can use the automated installation assistant. Run the following command in your terminal:

curl -sO https://packages.wazuh.com/4.5/wazuh-install.sh
curl -sO https://packages.wazuh.com/4.5/wazuh-install-files.tar
bash wazuh-install.sh -a

Once the installation finishes, the script will output the credentials to access the web interface. Make sure to save these in a secure password manager.
